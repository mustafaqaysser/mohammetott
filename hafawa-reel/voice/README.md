# مقاطع الصوت (Google AI Studio)

ولّد كل مقطع لحاله في Google AI Studio → Generate speech، بنفس الصوت ونفس «هوية الصوت» المعتمدة،
واحفظه هنا بنفس الاسم بالضبط (wav أو mp3)، ثم شغّل:

    python3 mix.py

السكربت يحط كل مقطع في وقته، ويخفض الموسيقى تحت الصوت تلقائيًا، ويطلع `hafawa-reel.mp4`.
